# KTDA Tea Farmers Management System

A comprehensive management system for KTDA (Kenya Tea Development Agency) tea farmers.

## Features

- **Interactive Map** - View tea zones, factories, farmers, and buying centers on an interactive map
- **Dashboard** - Real-time statistics and analytics with charts
- **Farmers Directory** - Complete list of registered farmers with contact information
- **Tea Delivery Tracking** - Record and track tea deliveries
- **Printable Reports** - Generate production and payment reports

## Live Demo

[View Live App](https://havillahchel.github.io/ktda-tea-farmers-app/)

## Technologies Used

- HTML5
- CSS3
- JavaScript
- Leaflet.js for maps
- Chart.js for analytics
- Font Awesome for icons

## Data Includes

- 3 Tea Factories (Rukuriri, Mungania, Kagwe)
- 3 Tea Zones (Rukuriri North, Rukuriri South, Mungania East)
- 8 Registered Farmers
- 5 Buying Centers
- Sample tea delivery records

## How to Use

1. Click on any location to zoom to it on the map
2. Use search filters to find specific items
3. Record tea deliveries using the delivery form
4. Generate printable reports
